# استوديو بصري — معرض أعمال ذكاء اصطناعي

موقع معرض أعمال عربي RTL مبني بـ React + Vite + Tailwind، مستوحى من محتوى مجلد **«حقيبة أعمالي»** في Google Drive. يجمع بين الأعمال المرئية، الفيديو، الصوت، والألعاب/التجارب التفاعلية في واجهة واحدة متجاوبة.

## المزايا

- واجهة عربية RTL بطابع تحريري/مختبر إبداعي.
- تصميم متجاوب للهاتف وسطح المكتب.
- مرشحات تفاعلية للأعمال حسب النوع.
- نافذة تفاصيل لكل مشروع مع روابط التجارب الأصلية.
- حركات دخول، تحويم، خلفيات ضوئية، واعتناء بـ `prefers-reduced-motion`.
- أصول صور مضغوطة بصيغة WebP داخل `client/public/assets` لتناسب الاستضافة الثابتة.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

## الفحص والبناء

```bash
pnpm check
pnpm build
```

ينتج البناء ملفات الموقع الثابتة داخل `dist/public`.

## الرفع على GitHub

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملفات المشروع كاملة، مع مجلد `client` وملف `package.json`.
3. فعّل GitHub Pages أو اربط المستودع بخدمة استضافة ثابتة.
4. استخدم أمر البناء `pnpm build`، واجعل مجلد النشر هو `dist/public`.

> روابط المشاريع الخارجية الموجودة في المعرض تشير إلى النسخ الأصلية في Drive وManus وGitHub كما كانت محفوظة في حقيبة الأعمال.
