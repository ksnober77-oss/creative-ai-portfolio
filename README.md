# استوديو بصري — معرض أعمال ذكاء اصطناعي

موقع معرض أعمال عربي RTL مبني بـ React + Vite + Tailwind، مستوحى من محتوى مجلد **«حقيبة أعمالي»** في Google Drive. يجمع بين الأعمال المرئية، الفيديو، الصوت، والألعاب/التجارب التفاعلية في واجهة واحدة متجاوبة.

## المزايا

- واجهة عربية RTL بطابع تحريري/مختبر إبداعي.
- تصميم متجاوب للهاتف وسطح المكتب.
- مرشحات تفاعلية للأعمال المختارة.
- أرشيف كامل يضم **48 ملفًا** من مجلد Google Drive، مع البحث والتصفية حسب النوع.
- معاينات مباشرة للصور وروابط آمنة للملفات الأصلية في Drive.
- نافذة تفاصيل للمشاريع الأساسية.
- حركات دخول، تحويم، خلفيات ضوئية، واعتناء بـ `prefers-reduced-motion`.
- أصول صور محلية مضغوطة بصيغة WebP لتناسب الاستضافة الثابتة.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

## الفحص والبناء

```bash
pnpm check
pnpm build
```

ينتج البناء ملفات الموقع الثابتة داخل `dist/public`.

## الرفع على GitHub Pages

المشروع مزود بملف Workflow في `.github/workflows/deploy-pages.yml`، ويستخدم مسارات نسبية حتى تعمل الأصول داخل رابط المستودع الفرعي. بعد تفعيل GitHub Pages من إعدادات المستودع باختيار **GitHub Actions**، يتم النشر تلقائيًا عند كل دفع إلى فرع `main`.

## ملاحظة حول ملفات Drive

تعرض الواجهة جميع سجلات مجلد «حقيبة أعمالي» وتفتح الملفات الأصلية من Google Drive. أما الصور فتظهر لها معاينات مباشرة من Drive. إذا تغيرت صلاحيات المشاركة في Drive، يجب جعل الملفات المراد عرضها متاحة لمن يملك الرابط حتى تظهر المعاينات والروابط للزوار.
